# Git Practice Project

This is a simple project I created to practise using **Git and GitHub**.

## About the Project

The project contains a basic webpage built with:

- HTML
- CSS
- JavaScript

The webpage contains a button that displays an alert when clicked.

## Project Structure

```text
scrimba-git/
├── index.html
├── style.css
├── script.js
└── README.md
```

## What I Am Practising

I am using this project to practise:

- Creating a Git repository
- Checking changes with `git status`
- Staging changes with `git add`
- Creating commits with `git commit`
- Viewing changes with `git diff`
- Working with branches
- Pushing code to GitHub
- Pulling changes from GitHub

## Basic Git Commands

```bash
git status
git add .
git commit -m "Your commit message"
git push
```
